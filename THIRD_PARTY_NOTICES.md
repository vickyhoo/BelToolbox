## DockWatch route data

Data/TransportRoutes.lua contains ship and zeppelin route coordinates, track samples and timing baselines from DockWatch, data revision 2026-10-13. TransportTimers.lua uses the same recorded-track projection approach for calibration. DockWatch's UI, media, flight timers, network synchronization and saved user data are not bundled.
